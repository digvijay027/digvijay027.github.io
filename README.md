# Digvijay Anand — Portfolio

A static portfolio website for GitHub Pages / Cloudflare Pages.

## Files
- `index.html` — portfolio content
- `styles.css` — responsive visual design
- `script.js` — small mobile-navigation interaction

## Free hosting: GitHub Pages

1. Create a public GitHub repository.
2. For a personal site, name it `<your-github-username>.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. In the repository, open **Settings → Pages**.
5. Under the publishing source, select the `main` branch and root folder.
6. Save and wait for GitHub Pages to publish.

GitHub Pages is available with GitHub Free for public repositories.

## Important
The portfolio intentionally describes professional slot-game work at a high level and does not include proprietary source code, internal game names, confidential mechanics, or employer assets.

Before publishing, verify that every external project link is still live and that you are comfortable making your contact information public.
